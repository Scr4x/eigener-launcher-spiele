# Eigener-Launcher – Spiele

Hier liegen die veröffentlichten Spiele und die Installationsdatei des **Eigener-Launchers**.

## Für Freunde & Familie

1. Unter **Releases** (rechts auf dieser Seite) die neueste Datei
   `Eigener-Launcher_…_x64-setup.exe` herunterladen und installieren.
2. Im Launcher unter **Entdecken** die Spiele auswählen und installieren.
3. Updates meldet der Launcher selbst – ein Klick auf **Aktualisieren** genügt.

## Inhalt

- `katalog.json` – Liste aller veröffentlichten Spiele (wird vom Launcher gelesen)
- Releases – die Spiele-Pakete und die Launcher-Installationsdatei
