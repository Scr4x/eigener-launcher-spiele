Eigener-Launcher

Das Programm für die Spiele aus unserer Runde. Einmal installieren, danach kommen neue Spiele und Updates von selbst.

Launcher herunterladen

Für Windows 10 und 11.

So installierst du ihn

Dauert zwei Minuten. Windows warnt dabei einmal, das ist bei kleinen Programmen normal.

  1. Datei herunterladen

    Klick oben auf Launcher herunterladen. Du bekommst die Datei Eigener-Launcher-Setup.exe.

    Meldet dein Browser, die Datei werde „nicht häufig heruntergeladen“: in der Download-Liste auf die drei Punkte bei der Datei klicken, dann Beibehalten. Fragt er noch einmal, auf Mehr anzeigen und Trotzdem beibehalten.

  2. Datei öffnen und auf „Weitere Informationen“ klicken

    Beim Öffnen erscheint ein blaues Fenster. Klick dort nicht auf „Nicht ausführen“, sondern auf den Text Weitere Informationen.

    Nachgebaut, so sieht es ungefähr aus:

    Der Computer wurde durch Windows geschützt

    Von Microsoft Defender SmartScreen wurde der Start einer unbekannten App verhindert. Die Ausführung dieser App stellt ein potenzielles Risiko für den PC dar.

    Weitere Informationenhier klicken

    Nicht ausführen

  3. „Trotzdem ausführen“ klicken

    Jetzt steht unten ein zweiter Knopf. Klick auf Trotzdem ausführen.

    Der Computer wurde durch Windows geschützt

    Von Microsoft Defender SmartScreen wurde der Start einer unbekannten App verhindert. Die Ausführung dieser App stellt ein potenzielles Risiko für den PC dar.

    App:Eigener-Launcher-Setup.exe
    Herausgeber:Unbekannter Herausgeber
    Trotzdem ausführen Nicht ausführen
    Warum warnt Windows? Windows kennt nur Programme, die bei Microsoft gegen Gebühr registriert sind. Unser Launcher ist das nicht, deshalb steht dort „Unbekannter Herausgeber“. Updates des Launchers und die Spieleliste sind mit einem eigenen Schlüssel unterschrieben, der Launcher prüft das bei jedem Update selbst.

  4. Installieren

    Das Installationsprogramm ist auf Deutsch. Klick dich mit Weiter und Installieren durch und am Ende auf Fertigstellen. Administratorrechte brauchst du nicht.

  5. Spiele holen

    Im Launcher oben auf Entdecken, dann beim Spiel auf Installieren. Danach findest du es unter Bibliothek.

Alle kostenlos und direkt im Launcher unter „Entdecken“.

Wenn etwas nicht klappt

Die häufigsten Fälle. Hilft nichts davon, schreib in die Gruppe und schick ein Foto der Meldung.

Beim Installieren eines Spiels steht „Zugriff verweigert (os error 5)“

Windows lässt den Launcher nicht in den Ordner schreiben, in dem die Spiele liegen. Das passiert oft im Ordner „Dokumente“, wenn der Ransomware-Schutz oder OneDrive aktiv ist.

So geht es: Im Launcher die Einstellungen öffnen und als Spieleordner einen Ordner außerhalb von Dokumente, Desktop und OneDrive wählen, zum Beispiel C:\Users\DeinName\Spiele. Dann das Spiel noch einmal installieren.

Im blauen Fenster gibt es keinen Knopf „Trotzdem ausführen“

Dann erlaubt dein PC grundsätzlich keine unbekannten Programme, etwa bei Schul- und Firmen-PCs oder wenn unter Windows 11 die „intelligente App-Steuerung“ eingeschaltet ist. In dem Fall lässt sich der Launcher leider nicht installieren. Melde dich in der Gruppe.

Wie bekomme ich Updates?

Der Launcher meldet sich selbst, wenn es eine neue Version gibt. Neue Spielversionen siehst du unter „Entdecken“ mit dem Knopf Aktualisieren. Deine Spielstände bleiben dabei erhalten.

Wie entferne ich den Launcher wieder?

Windows-Einstellungen, dann Apps, dann Installierte Apps, dort „Eigener-Launcher“ deinstallieren. Den Haken „Auch alle Spielstände löschen“ nur setzen, wenn du die Spielstände wirklich nicht mehr brauchst.
